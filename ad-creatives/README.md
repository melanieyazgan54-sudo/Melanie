# Ad Creatives

> Dieser Ordner enthält alle Werbeanzeigen-Briefings für Meta und TikTok Ads: Templates in `templates/`, fertige Briefings in `kampagnen/`.

## Ablauf

1. Neues Briefing aus `templates/creative-briefing-template.md` erstellen.
2. Hook aus `templates/hook-bibliothek.md` wählen oder neuen formulieren (dann dort ergänzen).
3. Datei speichern als `kampagnen/JJJJ-MM-TT-kurzbeschreibung.md`.
4. Nach dem Livegang: Kennzahlen im Abschnitt „Ergebnis" nachtragen.

## Regeln

- Pro Briefing genau **ein** Creative-Konzept. Varianten (anderer Hook, gleicher Body) bekommen eigene Dateien mit Verweis auf das Original.
- Jedes Briefing braucht: Zielgruppe, Angle, Hook, kompletten Text/Szenen-Ablauf, CTA und Erfolgskriterium.
- Keine unbelegten Behauptungen oder Heilversprechen (siehe `CLAUDE.md`, No-Gos).

## Beispiel

Ein vollständig ausgefülltes Briefing liegt in `kampagnen/2026-07-06-beispiel-problem-loesung-video.md` – neue Briefings sollen diesem Detailgrad entsprechen.
