# UGC-Skripte

> Dieser Ordner enthält Drehbücher für User-Generated-Content-Videos (TikTok, Reels, Ads): Template in `templates/`, fertige Skripte in `skripte/`.

## Ablauf

1. Neues Skript aus `templates/ugc-skript-template.md` erstellen.
2. Datei speichern als `skripte/JJJJ-MM-TT-kurzbeschreibung.md`.
3. Skript geht als Briefing an den Creator – es muss so konkret sein, dass der Creator ohne Rückfragen drehen kann.

## Regeln

- Ein Skript = ein Video. Länge 15–45 Sekunden, Hochformat 9:16.
- Gesprochener Text wörtlich ausschreiben (kein „Creator erzählt etwas über…").
- Jede Szene braucht: was im Bild ist, was gesagt wird, welches Text-Overlay erscheint.
- Sprache natürlich und gesprochen, keine Werbetexter-Floskeln – es soll wie eine echte Empfehlung klingen.
- Keine erfundenen Erfahrungsberichte als Fakten ausgeben: Der Creator spricht aus der Ich-Perspektive über die vorgesehene Story, echte Testimonial-Zitate nur mit Quelle.

## Beispiel

Ein vollständiges Referenz-Skript liegt in `skripte/2026-07-06-beispiel-problem-loesung.md`.
